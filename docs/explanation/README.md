# Explanation

Understanding-oriented documentation: discursive material on architecture,
trade-offs, and the rationale behind decisions that have not yet hardened
into ADRs.

## Canonical

- [**tau-philosophy.md**](tau-philosophy.md) — the project's vision and
  essence (2026-05-29). The current canonical statement of what tau is, what
  it is not, and the three convictions that drive every architectural
  decision. New contributors should start here.

## Historical lineage

- [tau-as-language.md](tau-as-language.md) — the 2026-05-02 precursor
  vision. Introduced the "compiled language for agentic workflows" framing
  that survives in the current philosophy. Referenced by ADRs 0014–0023.

## Operational

- [escape-hatches.md](escape-hatches.md) — registry of structural escape
  hatches (per ADR-0002). Updated alongside any PR that introduces,
  promotes, or removes one.
