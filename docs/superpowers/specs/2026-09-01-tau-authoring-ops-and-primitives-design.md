## 0. In one breath

> **tau compiles agent definitions into sealed artifacts you can prove things
> about** — test them deterministically, review their power changes in CI, and
> run them from any language. Authors work in three surfaces — TOML declares
> the vocabulary, TypeScript choreographs the flow, Rust implements the muscle
> — all lowering through one validator into a frozen, content-hashed IR. The
> engine stays 100% Rust; TypeScript runs only at synth time (~300 ms,
> sandboxed) and never at runtime.

Product arc: **v1** = the maker's loop (one person, one repo, one machine:
author → prove → run). **v2** = the artifact travels (signed OCI distribution,
universal consumer SDK, environments/promote, MCP facade, second authoring
language). **v3** = the fleet (matrix, catalog, policy packs). Each version is
the previous version's artifact plus one verb; the frozen IR and the synth
contract carry the whole arc.

## 1. The three surfaces (the strict split)

| Surface | Role | Contains |
|---|---|---|
| **TOML / dirs** | the vocabulary | agents (markdown + frontmatter under `agents/`), models, `[allow]` (**never emittable by code**), MCP tool contracts, triggers, context pipelines. Pure data — no templating, expressions, or includes, ever (the Helm-cycle rule). |
| **TypeScript** | the choreography | `pipelines/` — one file = one pipeline, id = file path ([dirs]-style scanning per ADR-0069/0070). Flow only: never prompts, models, tools, or capabilities. |
| **Rust** | the muscle | `#[tau::tool]`, `#[tau::deterministic]` + explicit `tau::export![]`. Name, schema, description, and capabilities derive from the signature + attribute. `[steps]` and `[tools] native=` are removed from TOML (deprecate-warn one cycle). |

Rationale: one declaration per fact; the constitution is never generated by
the thing it governs; each category of primitive has one natural surface.

**The synth contract.** `tau.toml` stays the root (`[synth] entry`,
`format`). tau spawns the entry (Node/tsx default; runner overridable) under
`tau-sandbox-native` (no network, fs read-only in the project); the program
emits canonical `ProjectConfig`-shaped JSON (`synth_format`-gated, strict per
ADR-0065) on stdout; it merges at the *unchecked* level before the single
`validate()` (the ADR-0069 discipline; collisions are hard errors). Governance
is never delegated to the SDK: a hostile synth program can only emit config
that `tau check` fully re-validates. Hermeticity: sandbox + CI double-synth
byte-identity check. `tau.gen.ts` — generated inside `tau dev`/build,
committed, **registry-content-hash-stamped** (stale gen = loud build error,
the anti-Prisma rule) — exposes typed bindings for agents, models, tools,
deterministic fns, agent kinds.

**Multi-pipeline & imports.** IR `workflow.pipeline: Option<Pipeline>` grows
to `pipelines: BTreeMap<PipelineId, Pipeline>` (the one MAJOR ir_format bump,
v3.0.0; single `[pipeline]` remains the legacy degenerate case). Pipelines
import each other and mount as sub-flow steps (`Compose` unblocked): acyclic
(cycle = synth error), mounted steps namespaced under the call-site id,
capabilities unchanged (same project, same `[allow]`).

**Legacy lanes.** `tau-ts-extract` static factories and the TOML-emitting
Python SDK **are deleted in Phase 1** (when their replacement lands); the
TOML-bridge/one-validation-path pattern is harvested. `tau-workflow` v1
(crate + CLI verbs + docs) is deleted in Phase 0 (superseded twice).

## 2. The IR and the journal

**The IR, justified correctly** (the spec retires "the IR is for
portability"): the `no_std` engine makes *execution* portable; the IR's four
irreducible jobs are (1) the **frozen resolved identity** every ops verb
operates on (pin/plan/promote/replay — pinning unresolved config would pin
sand); (2) the **artifact that crosses the build/run boundary** (std
resolution machinery cannot enter the guest); (3) the **source for per-target
compilation** (capability_fit/feature_fit, future AOT); (4) the **decoupler**
between the fast-churning authoring surface and slow-moving runtimes.
Contracts restated: *authoring contract* = ProjectConfig/synth; *artifact
contract* = IR + WIT.

**The journal (Temporal-model, replaces HTTP-VCR cassettes).** Every
nondeterministic boundary crossing is a typed, recorded event keyed
`(instance path, per-instance seq)` — never global order: LLM completions
(with request hash), tool results, event deliveries, timer firings, spawn
admissions/denials, judge verdicts, clock/random reads, compactions, signals,
budget-tranche transitions, cancellations. The interpreter is a pure function
of (frozen IR, journal); observable scheduling is journal-derived or seeded.
Three views over one append-only file (`.tau/runs/<id>/journal.jsonl`,
interchange-versioned): **durability** (resume = fast-forward through the
journal; per-turn snapshots remain as a replay-shortcut optimization),
**testing** (`tau record`/`tau replay`; request-hash mismatch = a *named*
`ReplayDivergence`, unlike VCR's silent false green; `--live-tools` mode
replays decisions but executes tools), **audit** (the journal is the answer to
"what did this run do"; OTel span mapping). tau takes Temporal's journal
without Temporal's versioning curse: runs bind to an immutable IR hash, and no
user code is ever replayed. Anchor: Burckhardt et al., OOPSLA 2021.

## 3. The agentic instruction set

### 3.1 The taxonomy — eight construction primitives

Assignment rule: each primitive lives in exactly ONE category (its nature);
cross-category uses are *patterns* (e.g. "agents coordinate via the
blackboard" = a Messaging pattern over Storage).

| Category | Members | Status |
|---|---|---|
| **Flow** | sequence · Branch · Loop · ForEach · Parallel · Compose · Dynamic (delegation) · Explore (bounded autonomy) · per-step retry/catch · on_exit | 6 exist, 4 new, 1 unblock |
| **Compute** | Agent (LLM) · Tool (native/MCP) · Deterministic (pure fn) · Judge (evaluative LLM) | exist; user fn registry to wire |
| **Storage** | step outputs · variables + reducers · blackboard (tasks + shared notes) · file artifacts · exploration scratchpad · conversation context · checkpoints · the journal (master store) | journal & variables new |
| **Messaging** | EmitEvent ↔ WaitForEvent (correlation keys) · resume signals · call-and-return · typed human elicitation (resume_schema) | mostly new (v2) |
| **Time** | Sleep (duration/until) · per-step timeout · timeout-vs-event race · Trigger (cron/manual/webhook/event, with declared input) | new (v2) |
| **Governance** | `[allow]` · capabilities/ceilings/envelopes · budgets (tokens/turns/duration + synthesis reserve) · bounds (iters/spawns/concurrency) · late binding under a declared ceiling · sandbox/wasm enforcement | exists — extended |
| **Verification** | Check · goals (predicate algebra: numeric compare, and/or/not, two-locus) · deliverables (judged, retryable) · guardrails (placed checks) · quality-retry rewind · conformance | exists — ahead of the field |
| **Observability** | run events (incl. new pipeline/step/check variants) · trace/OTel spans · `tau plan` (semantic diff) · `tau inspect` (capability card) · provenance | exists + repairs |

Transverse guarantees (never manipulated, always present): **Identity**
(hierarchical lineages per ADR-0070, content hashes, `[[moved]]` rename
records) and **Contracts** (versioned, drift-tested schemas).

Beneath the taxonomy sit the **seven engine foundations** (what tau is made
of, engine-side): Seal (canonical form + hash), Lineage (hierarchical
namespace + subtree ownership), Contract (versioned schema), Formula
(registered pure function), Gate (mediated effect port), Ledger (append-only
journal; state = a fold of the ledger), Ceiling (compiled limit checked at
every crossing). Admission rule: any future feature must be expressible as an
assembly of these seven; needing an eighth is a major architectural event
(foundational ADR, not a feature).

### 3.2 The step kinds (15) and transverse planes

`Agent · Tool · Deterministic · Check · Branch · Parallel · Loop · ForEach ·
Sleep · WaitForEvent(⊇ Suspend) · EmitEvent · Dynamic · Explore · Compose`
(+ `Suspend` retained until absorbed). Copied semantics: ForEach = ASL
Distributed Map (runtime collection, per-item retry/tolerance,
max_concurrency, reduce via deterministic fn); per-step retry/catch = ASL's
per-state Retry+Catch (the **fault plane**, distinct from the existing
**quality plane** Check→rewind); WaitForEvent correlation = Inngest
match/Restate awakeables; variables+reducers = LangGraph channels ∘ ASL
Assign. New step kinds are MINOR ir_format bumps (precedent: v2.4.0); only
multi-pipeline is MAJOR.

**Explore (Option B, evidence-locked):** driver agent loop + optional flat
spawns (depth 1, reusing Dynamic machinery: pooled counters, envelope meet,
soft denial) + **mandatory budget** (tokens/turns with `synthesis_reserve`;
budget injected into context each turn; exhaustion = forced synthesis mode,
never a mid-thought kill) + **exit** = judged deliverable with bounded retry,
or best-effort/fail on exhaustion + notes artifact + optional
`require_plan` (Gemini pattern: plan-explore → Suspend → execute-explore) and
capability-gated `checkpoint.request`. The box (goal, ceiling, budget, spawn
bounds, exit, model allowlist, compaction policy) is compiled and on the
card; the interior is free. Rejected: tree search (ToT/LATS/MCTS — judge
noise, no production evidence), runtime graph mutation/handoffs (CrewAI
drift evidence), prompt-level enforcement, invisible budgets, deep spawn
nesting, confidence-threshold exits.

### 3.3 Kernel closed, vocabulary open — primitive packs

The kernel (step kinds + planes) extends by ADR only. User-defined primitives
are **primitive packs** (the Bazel model: IR = actions, packs = rules): one
npm/git package = a typed fragment (`defineFragment`, `(scope, id, props)`,
namespace-owned) + optional Rust crate (tools/fns with declared caps) +
replay fixtures (packs arrive *proven*) + docs auto-generated from the props
schema. `tau new fragment` scaffolds; capability transparency is structural
(a flow-only pack has no powers; a pack's Rust caps are audited at install
and bounded by the consumer's `[allow]`). Extension rule per category: Flow /
Messaging / Storage substrates / Identity → ADR; Compute fns, Verification
predicates, context transformers → packs; Governance → versioned capability
vocabulary (ADR-0036); Time / Observability → adapters / additive schemas.
Proof-of-sufficiency pack: **best-of-N** = `ForEach(1..n) → judge-reduce`.
Named communication packs: rpc (correlated Emit+Wait pair), broadcast, inbox
(blackboard discipline).

### 3.4 The repairs lot (silent-promise defects found by the code audit)

All are v1: `AgentBudget.max_tokens` parsed but never read · `judge_model`
accepted but a runtime no-op · `output_schema` runtime-inert (wire to
structured output / validation) · **`any-wasi-strict` declares
`supported_features: &[]`** while the guest already links `run_pipeline`
(ADR-0068 accepted — a stale registry entry denies the flagship target all
control flow) · pipelines emit **no RunEvents** (add
StepStarted/StepCompleted/CheckEvaluated/Suspended — additive run-event
schema; required by the NDJSON interface contract) · subflow args not
forwarded · cassette global-turn keying (superseded by the journal) · goals
hardcoded `OnFail::Abort` (make retry authorable) · predicate algebra +
structured template access `${steps.x.output.field}` (JSON-pointer read only
— transformations stay deterministic fns) · scalar-coercion footgun of
rendered args · capability-order-sensitive hashes · stale wasm comments ·
decorative `max_concurrency`.

## 4. The TypeScript API (audit-locked decisions)

Scope+callback style with **typed, non-coercible handles** (no `toString`, no
truthiness — the CDK-token scar; interpolation only via the tagged template);
predicates = closed vocabulary as handle methods + `.and/.or/.not`
combinators (never lambdas — Mastra's unserializable-closure scar); loop
callback returns a `Predicate` object (a plain boolean is a synth error);
explicit ids, collision = synth error (never auto-suffix), rename = breaking
with `[[moved]]` records that drive both `tau plan` rendering
(rename-not-replace) and checkpoint remap; statement order ≠ execution order
(documented + unconsumed-step lint); fragments are the blessed reuse unit;
source-mapped synth errors (file:line, never JSON pointers) are a v1
requirement, not polish. L1 factories generated from the published
project-manifest schema (`schemas/project-manifest/`, generated +
drift-tested like `schemas/ir/`).

## 5. The ops lane (IaC on the current machine first)

The machine is environment `local` (implicit until a second env exists); the
pin lives in committed, secret-free `.tau/envs/local.state.toml`. Verbs:
**`tau plan`** — semantic diff (source-vs-pin, pin-vs-pin, `--check` for CI)
rendered in IR vocabulary with **capability changes always first**; versioned
`schemas/plan/` JSON twin; exit codes 0 (no change) / 2 (changes) / 3
(**widens capabilities**) / 1 (error). **`tau apply`** — atomic per repo
(one bundle, one pin; `--pipeline` slicing as the escape valve), emits
substrate adapters (systemd-user timers; k8s later) from `[trigger]`
declarations ("compile the trigger, delegate the substrate", ADR-0043).
**`tau record` / `tau replay`** — journal views. **`tau inspect`** — the
permission-sheet rendering of the capability card (a designed object; with
`--attempt` to demonstrate denial). Wasm bundles are **run-or-refuse** per
environment (structural capabilities cannot be narrowed post-build;
narrowing is host-sandbox-tier only; different profiles = different declared
builds, pinned separately — build-once-promote is preserved, never violated).
Fragment provenance: `tau-lock.toml` gains a `[synth]` section (SDK version,
gen hash, fragment resolved SHAs) — lockfile schema v8, additive.
Environments/promote/fleet are v2/v3 on the same model.

## 7. Use cases (validated adversarially)

**Independent workflows** — the v1 golden path; `[trigger].input` added.
Shared-fate clauses accepted: per-file synth error isolation; atomic repo
apply; one fragment version per repo. **Custom harnesses** — Rust today via
the embed prelude; any language after serve v2; token streaming through the
sync WIT `complete` import is honestly deferred (γ). **Software factory** —
deliverables+judge+dynamic+suspend align strikingly; dynamic planning is
answered by two documented patterns (two-phase task-list → dynamic region;
the outer loop in CI where the factory regenerates its own `pipelines/*.ts`
and `tau plan` gates its own power) — runtime self-modifying graphs are
refused by construction, in writing. **Agents authoring workflows** — the
split makes it safe by construction (an agent writes choreography, never the
constitution); official authoring skill + `tau new` scaffolder + plan-exit-3
PR gate (v1). Deliberate non-goals unchanged: simple web chatbots, generic
ETL (NG5).

## 9. Prior art and novelty (literature-checked)

Ancestry per category is deep and must be cited: Workflow Patterns Initiative
(van der Aalst et al. 2003; Russell et al., MIT Press 2016 — control-flow/
data/resource/exception families; their patterns-as-benchmark method is the
role this taxonomy plays for agentic engines) · workflow nets (Aalst 1998) ·
actor model (Hewitt 1973), CSP (Hoare 1978), π-calculus (Milner 1992) ·
Linda/generative communication (Gelernter 1985; Gelernter & Carriero 1992) ·
blackboard systems (Hearsay-II, Erman et al. 1980; Nii 1986) · durable
execution formalized (Burckhardt et al., OOPSLA 2021) · capabilities (Dennis
& Van Horn 1966; Miller 2006) · design by contract (Meyer 1992) ·
LLM-as-judge (Zheng et al. NeurIPS 2023; Gu et al. 2024 — adopt their judge-
bias catalogue as a design force) · AgentOps observability taxonomy (Dong et
al. 2024) · agent pattern catalogues (Anthropic 2024 — their five patterns
are compositions of these categories; Liu et al., JSS 2025) · nearest
contemporaneous systems: CaMeL/Progent (runtime governance, 2025), AgentSPEX
/ POLARIS (2026 — **read full texts before publishing novelty claims**).

Calibrated novelty claims: compiled capability governance as a
workflow-language construct; budgeted bounded-autonomy regions with a
synthesis reserve (no occurrence found); judged deliverables wired into
durable control flow as typed rewind; semantic plan/diff of definitions
(process-model differencing ~2008–11 is prior art in a different setting);
the workflow-level capability card (A2A cards describe agents); and above
all **the integration** — no published taxonomy spans all eight categories.
Claim it the way WPI did: tau is to this taxonomy what YAWL was to the
workflow patterns.

Adopted from the literature: separation-of-duties naming (judge ≠ producer);
escalation chains for human elicitation; the data-visibility lattice as the
citation for Storage scoping; a future soundness story for the Flow subset.

## 10. Decisions ledger (locked)

1. Ops-lane-first scope; maintainability + local apply as v1 center.
2. Deep + wide growth; multi-pipeline repos, file-path pipeline identity.
3. Parameterized composition in the code lane; fragments `(scope, id, props)`.
4. TypeScript flagship; language-agnostic synth-subprocess contract; Starlark
   reserved as a possible future frontend; approach = subprocess synth
   emitting ProjectConfig JSON (embedded runtime and stretched static
   extraction rejected).
5. Strict three-surface split; `[allow]` TOML-only forever; `[steps]` and
   `[tools] native=` removed; agents/models TOML-dirs-only.
6. Machine = env `local`; pins committed; atomic apply (+ `--pipeline` valve);
   wasm run-or-refuse; env narrowing host-tier only.
7. Cross-repo fragments as plain npm/git packages; `[synth]` provenance in
   lockfile v8; no tau registry; `tau add` unification (agent packs = δ.1
   pulled to v2).
8. Legacy TS/Python authoring lane deleted in Phase 1; `tau-workflow` deleted
   in Phase 0; ADR wave incl. argued amendment of the ROADMAP "killed item"
   (narrowed: killed as canonical source *of agents/models/tools* — upheld).
9. Exposure: generated SKILL.md + AGENTS.md emitter v1; MCP facade v2; typed
   client v2.5; agent-grade CLI (≤1,500-token help, deterministic exits).
10. Journal (Temporal model) as the single record substrate; HTTP-VCR
    retired; snapshots as optimization; `tau record/replay` = journal views.
11. The 15-step-kind kernel, eight-category taxonomy, seven foundations,
    primitive packs, and the repairs lot as scoped in §3.
12. Host tools: declared + schema-validated + card-labeled `host-enforced`;
    session tooling via late binding under a declared ceiling; serve v2 adds
    `session.*` + reverse dispatch.
13. Vision reframe: "the tau SDK" = one language-plural product (authoring
    bindings + engine API), generated from schemas; consumer-first in
    non-flagship languages; Constitution G6 to be amended accordingly.

**Residual open items (small, for the ADR/implementation phase):** whether
exit handlers subsume saga-compensation semantics; full-text review of
AgentSPEX/POLARIS before public novelty claims; `PARALLEL_CAP`
configurability shape; exact `[synth]`/state-file field lists; systemd/k8s
retry-policy encoding in emitted adapters (currently dropped — fold into the
Time/trigger ADR).

## 12. Requirements, not polish (persona-derived)

The permission sheet (`tau inspect` as an app-store-grade rendering);
cassette/journal honesty (recording age shown, `--refresh` flow); plan
signal discipline (only governance deltas may be loud); source-mapped synth
errors. Plus: zero mandatory concepts before the first run — every ops
feature is opt-in by file presence; rung N never taxes rung N−1.
