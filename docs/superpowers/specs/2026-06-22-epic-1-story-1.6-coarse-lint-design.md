# EPIC 1 · Story 1.6 — Coarse-ceiling lint (design)

**Date:** 2026-06-22
**Status:** Approved (brainstorm complete; awaiting implementation plan)
**Story:** vision-roadmap EPIC 1 · 1.6 — "Lint warning for coarse ceilings
(`network=["*"]`)."
**Constitution:** [ADR-0057](../../decisions/0057-root-allow-governance.md)
(1.6's `network=["*"]` lint targets `hosts=["*"]` within the capability shape).
**Consumes:** the 1.4/1.5 `governance` check category.

## Purpose

Warn — never fail — when an `[allow]` ceiling entry is so broad it defeats the
point of a constitution (`hosts=["*"]`, `fs.read=["/**"]`, …). This is the final
EPIC 1 story: the enforcement is done (1.4/1.5); 1.6 adds an ergonomics nudge
toward tight ceilings.

## Design decisions (locked in brainstorm)

**Coarseness = absolute wildcards only.** The lint flags *only* ceiling entries
that admit **everything** of their kind — the "you've written a ceiling that
isn't a ceiling" case. It deliberately does NOT flag normal scoped globs like
`/proj/**` (that is the correct way to scope a subtree). Rationale: a lint's
value is its signal-to-noise; every warning must correspond to a real hole or
developers tune the whole category out.

**Scope = constitution surfaces only.** Lint the root `[allow]` ceiling and each
`[allow.tools.<name>].ceiling`. Do NOT lint package caps, `[tools.*]`
definitions, or agent overrides — those are already bounded by the ceiling
(1.5's L0/L2 guarantee instance ⊆ ceiling), so a wildcard under a tight ceiling
can't reach anything wild; warning about it would be a false alarm.

**Severity = `Warning`.** Exit code stays 0. Only runs when `[allow]` is present
(absent `[allow]` is already covered by the existing opt-in `Warning`). No
suppression mechanism (it fails nothing; YAGNI).

## Coarse patterns

```rust
/// Coarse (admits-everything) entries in a ceiling capability, as
/// (kind, offending-entry) pairs. Empty = not coarse.
fn coarse_hits(cap: &Capability) -> Vec<(&'static str, String)>;
```

| kind | flagged when a list element is |
|---|---|
| `net.http` (hosts) | `== "*"` |
| `process.spawn` (commands) | `== "*"` |
| `fs.read` / `fs.write` / `fs.exec` (paths) | `∈ {"/**", "**", "/*"}` |

Other kinds (`agent.spawn`, `skill.spawn`, `task_list`, `plan`, `custom`) have no
coarse form in scope → no hits. `Capability` is `#[non_exhaustive]` → a catch-all
arm returns no hits.

## The pass

A new `coarse_lint(allow: &AllowConfig, tau_toml: &Path, out: &mut Vec<CheckFinding>)`
in `governance.rs`, called from `governance_findings` on the `Some(allow)` path
(alongside `over_reach` / `closed_world` / `lattice`):

- For each cap in `allow.ceiling`: `coarse_hits(cap)` → one Warning per hit,
  subject `[allow]`.
- For each `(name, entry)` in `allow.tools`, for each cap in `entry.ceiling`:
  `coarse_hits(cap)` → one Warning per hit, subject `[allow.tools.<name>]`.

## Finding shape

`CheckFinding { category: Governance, severity: Severity::Warning, rule_id:
"tau.governance.coarse_ceiling", summary, location: Some(loc(tau_toml)),
structured }`. `summary` names the surface + kind + entry, e.g.:

```
[allow] net.http host "*" is a coarse ceiling — list specific hosts to tighten the constitution
[allow] fs.read path "/**" admits the whole filesystem — scope it to the paths you need
[allow.tools.fetch] net.http host "*" is a coarse ceiling — list specific hosts
```

`structured`: `{ "check": "coarse_ceiling", "surface": "[allow]"|"[allow.tools.<name>]",
"kind": "...", "entry": "..." }`.

## Testing (unit, from TOML fixtures — pure, no manifest)

In `governance.rs` `tests` (reuse `proj()` / `summaries()`):

- Root `[allow]` with `net.http hosts=["*"]` → one `coarse_ceiling` Warning
  naming `net.http` / `*`.
- Root `[allow]` with `fs.read paths=["/**"]`, `fs.write paths=["**"]`,
  `fs.exec paths=["/*"]` → three Warnings (one per coarse path).
- `[allow.tools.x]` ceiling with `hosts=["api.x.com", "*"]` → one Warning naming
  `[allow.tools.x]` and `*` (specific host silent).
- `process.spawn commands=["*"]` → Warning.
- A fully-scoped `[allow]` (`fs.read=["/proj/**"]`, `net.http hosts=["api.x.com"]`,
  `process.spawn commands=["git"]`) → **no** `coarse_ceiling` findings.
- A coarse-only project → `compute_exit` still 0 (Warning does not fail).
- No `[allow]` → no `coarse_ceiling` findings (the opt-in Warning path is
  unchanged).

## Out of scope

Package caps / `[tools.*]` / agent-override linting; system-root heuristics
(`/home/**` etc.); any suppression/allow-coarse escape hatch; changes outside
`governance.rs`.

## Crates touched

`tau-cli` only — `cmd/check/categories/governance.rs` (add `coarse_lint` +
`coarse_hits` + unit tests). No new files, no other crate.
