# `tau build` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the MVP `tau build` producer per spec `2026-05-27-tau-build-design.md`: a single CLI command that gathers a fully-installed tau project's resolved state and emits a byte-stable `.tau` bundle.

**Architecture:** Producer code lives in `tau-pkg::bundle::build` next to the §C.1 manifest/canonical/hash modules. 7-step pipeline (load → verify install → gather → assemble → write). Thin CLI shim in `tau-cli::cmd::build` maps `BuildError` to exit codes. Reuses existing `tree_hash` (priority 7), `compute_effective` (priority 4, already lifted to tau-pkg), `LockFile::load`, `Scope::resolve`. One amendment to §C.1's `compute_self_hash` to exclude `bundle.created_at` from the hash domain so bundles are reproducible.

**Tech Stack:** Rust 2021, `serde` + `toml` for I/O, `sha2`/`hex` (already workspace deps), `chrono` for timestamps. No new transitive deps.

**Cargo rules (CLAUDE.md):** Every cargo invocation MUST use `timeout <T> env CARGO_INCREMENTAL=0 CARGO_TARGET_DIR=target/agent-impl cargo <verb> -p <crate>`. Commits use `--no-verify` with `-c user.name="Titouan Lebocq" -c user.email="lebocq.tit@gmail.com"`. NEVER run `git stash` in this worktree (auto-pop bug).

**Spec amendment:** §4.1 of the spec ("`compute_effective` layering") is moot — the lift to `tau-pkg` already happened 2026-05-17. Use `tau_pkg::capability_override::compute_effective` directly. Update the spec accordingly in Task 12.

**Pre-existing state (verified):**

/// Canonical sentinel timestamp used by `compute_self_hash` to zero
/// the `bundle.created_at` field before canonicalizing. UNIX_EPOCH is
/// guaranteed RFC3339-valid and stable across `chrono` versions.
const ZEROED_TIMESTAMP: chrono::DateTime<chrono::Utc> = chrono::DateTime::UNIX_EPOCH;

/// Compute the canonical SHA-256 of a manifest with the `bundle.sha256`
/// and `bundle.created_at` fields zeroed. Does NOT mutate the input.
///
/// `created_at` is excluded so two builds of identical source produce
/// identical hashes (per spec §C.2 stable-bundles decision). The field
/// is preserved in the final on-disk manifest — only the *hash domain*
/// excludes it.
pub fn compute_self_hash(manifest: &BundleManifest) -> String {
    let mut clone = manifest.clone();
    clone.bundle.sha256 = String::new();
    clone.bundle.created_at = ZEROED_TIMESTAMP;
    let canonical = to_canonical_toml(&clone);
    let mut hasher = Sha256::new();
    hasher.update(canonical.as_bytes());
    hex_encode(&hasher.finalize())
}
```

/// Returns the `native-<host-os>-strict` triple for the platform this
/// binary runs on. Used by callers (e.g. `tau build`) that need a
/// sensible default target when no `--target` flag is supplied.
///
/// # Panics
///
/// Panics on a platform tau doesn't have a `native` adapter for
/// (currently anything other than Linux / Darwin / Windows). The
/// resolver's Available registry intentionally has no entry for such
/// platforms, so panicking here is the correct fail-loud behavior —
/// adding a new host requires explicit ADR work, not silent fallback.
pub fn host() -> TargetTriple {
    let platform = if cfg!(target_os = "linux") {
        crate::target::platform::Platform::Linux
    } else if cfg!(target_os = "macos") {
        crate::target::platform::Platform::Darwin
    } else if cfg!(target_os = "windows") {
        crate::target::platform::Platform::Windows
    } else {
        panic!(
            "tau has no native adapter for target_os={}; \
             add an entry to the target registry first",
            std::env::consts::OS,
        );
    };
    TargetTriple {
        platform,
        adapter_family: crate::target::adapter_family::AdapterFamily::Native,
        tier: crate::sandbox::SandboxTier::Strict,
    }
}
```

//! `BuildError` — typed failure type for the bundle build pipeline.

use std::path::PathBuf;

/// Errors returned by [`crate::bundle::build`].
///
/// Each variant maps to a CLI exit code via `tau-cli::cmd::build`:
/// config/parse errors → 2, install-state errors → 3, internal/IO
/// errors → 70.
#[derive(Debug, thiserror::Error)]
pub enum BuildError {
    /// Loading `tau.toml` failed (parse or IO).
    #[error("failed to load project tau.toml: {0}")]
    ProjectConfig(String),

    /// `tau.lock` is missing entirely. Caller should run `tau install`.
    #[error("missing lockfile; run `tau install` first")]
    MissingLockfile,

    /// `tau.lock` is present but failed to parse.
    #[error("failed to load lockfile: {0}")]
    LockfileLoad(String),

    /// A locked package's directory doesn't exist on disk.
    #[error("package `{name}` is locked but not installed at {path:?}; run `tau install`")]
    PackageNotInstalled { name: String, path: PathBuf },

    /// `tree_hash` failed for an installed package directory.
    #[error("tree hash failed for `{name}`: {source}")]
    TreeHashFailed {
        name: String,
        #[source]
        source: crate::tree_hash::TreeHashError,
    },

    /// Reading/hashing an agent's system_prompt file failed.
    #[error("system prompt resolution failed for agent `{id}`: {source}")]
    PromptResolveFailed {
        id: String,
        #[source]
        source: std::io::Error,
    },

    /// `compute_effective` rejected the agent's project-override.
    #[error("capability override compute failed for agent `{id}`: {source}")]
    CapabilityOverrideFailed {
        id: String,
        #[source]
        source: crate::capability_override::OverrideExpandError,
    },

    /// Manifest assembly failed (e.g. impossible schema state).
    #[error("manifest assembly failed: {0}")]
    ManifestInvalid(String),

    /// Writing the bundle file to disk failed.
    #[error("bundle write failed at {path:?}: {source}")]
    WriteFailed {
        path: PathBuf,
        #[source]
        source: std::io::Error,
    },
}
```

pub fn build(opts: BuildOptions) -> Result<BundleArtifact, BuildError> {
    // Step 1: Load tau.toml. We use serde+toml directly because the
    // existing tau-pkg config loaders are scope-aware and pull in
    // extra resolution we don't need here.
    let tau_toml_path = opts.project_root.join("tau.toml");
    let tau_toml_bytes = std::fs::read(&tau_toml_path)
        .map_err(|e| BuildError::ProjectConfig(format!("read {tau_toml_path:?}: {e}")))?;
    let _project_toml: toml::Value = toml::from_slice(&tau_toml_bytes)
        .map_err(|e| BuildError::ProjectConfig(format!("parse {tau_toml_path:?}: {e}")))?;

    // Step 2: Load tau.lock. Distinguish "missing entirely" from
    // "present but invalid" so the CLI can show a remediation hint.
    let lockfile_path = opts.project_root.join("tau.lock");
    if !lockfile_path.exists() {
        return Err(BuildError::MissingLockfile);
    }
    let _lockfile = crate::lockfile::LockFile::load(&lockfile_path)
        .map_err(|e| BuildError::LockfileLoad(e.to_string()))?;

    unimplemented!("steps 3-7 in subsequent tasks")
}
```

fn sha256_hex(bytes: &[u8]) -> String {
    use sha2::{Digest, Sha256};
    let mut h = Sha256::new();
    h.update(bytes);
    let digest = h.finalize();
    let mut s = String::with_capacity(64);
    for b in digest.iter() {
        use std::fmt::Write as _;
        write!(&mut s, "{b:02x}").unwrap();
    }
    s
}

//! `tau build` — see spec `2026-05-27-tau-build-design.md`.

use std::process::ExitCode;

use tau_pkg::bundle::{build, BuildError, BuildOptions};
use tau_ports::target::TargetTriple;

/// CLI entry point. Resolves the project root from cwd, calls
/// `tau_pkg::bundle::build` with host target + default output, prints
/// progress to stderr + the bundle path to stdout, returns the
/// appropriate exit code per spec §6.
pub fn run() -> ExitCode {
    let project_root = match std::env::current_dir() {
        Ok(p) => p,
        Err(e) => {
            eprintln!("error: cannot determine current directory: {e}");
            return ExitCode::from(70);
        }
    };
    let opts = BuildOptions {
        project_root,
        target: TargetTriple::host(),
        output_path: None,
    };

    // Progress messages are best-effort. They print before each step
    // so the user sees motion even on a slow build.
    eprintln!("Building bundle…");

    match build(opts) {
        Ok(artifact) => {
            eprintln!(
                "Wrote bundle: {} (sha256: {}…{}, {} bytes)",
                artifact.path.display(),
                &artifact.sha256[..6],
                &artifact.sha256[artifact.sha256.len() - 6..],
                artifact.size_bytes,
            );
            // stdout is the bundle path, so `tau run --bundle "$(tau build)"` works.
            println!("{}", artifact.path.display());
            ExitCode::SUCCESS
        }
        Err(e) => {
            eprintln!("error: {e}");
            ExitCode::from(exit_code_for(&e))
        }
    }
}

fn exit_code_for(err: &BuildError) -> u8 {
    match err {
        BuildError::MissingLockfile | BuildError::PackageNotInstalled { .. } => 3,
        BuildError::ProjectConfig(_)
        | BuildError::LockfileLoad(_)
        | BuildError::ManifestInvalid(_) => 2,
        BuildError::TreeHashFailed { .. }
        | BuildError::PromptResolveFailed { .. }
        | BuildError::CapabilityOverrideFailed { .. }
        | BuildError::WriteFailed { .. } => 70,
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn exit_code_mapping_per_spec() {
        assert_eq!(exit_code_for(&BuildError::MissingLockfile), 3);
        assert_eq!(
            exit_code_for(&BuildError::ProjectConfig("x".into())),
            2,
        );
        assert_eq!(
            exit_code_for(&BuildError::WriteFailed {
                path: "/dev/null".into(),
                source: std::io::Error::new(std::io::ErrorKind::Other, "x"),
            }),
            70,
        );
    }
}
