Bucket legend:

  • LIVE-DOCUMENTED — needs a real upstream service / credential. Legitimately #[ignore]'d by default; opt-in via env var. Should never block CI.

  • DEFERRED — waiting on an explicit dependency (helper, fixture, sibling PR). Should reference what is being awaited.
