Workflow step input templating.

Recognizes two reference forms:

  • ${input} → the workflow’s user-supplied input string.
  • ${steps.<id>.output} → the prior step’s output, by id.

Both are resolved at step-dispatch time, after that step’s preceding steps have completed. Forward references (a step referencing a later step) are detected at workflow-parse time in the runner before any step runs — see runner.rs.

resolve
Resolve ${...} references in template against input + prior step outputs. Unknown references produce WorkflowError::TemplateUnresolved with workflow and step_id populated by the caller (we don’t know them here).
