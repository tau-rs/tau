Module cmd

Subcommand handlers. Each subcommand has its own submodule with a pub async fn run(args: &<SubArgs>) -> anyhow::Result<()> entry point.

Tasks 10-14 implement each handler. At Task 4 they are stubs returning an “unimplemented” error.
