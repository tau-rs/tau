pub async fn run_printer(
    rx: UnboundedReceiver<TraceEvent>,
    output: &mut Output,
) -> BTreeMap<String, AgentStats>
Expand description

Drain rx until the channel closes, rendering the trace live through output. Returns the final aggregated stats keyed by agent id.

Honors --json: in human mode one padded line is emitted per significant event via Output::human; in JSON mode each raw [TraceEvent] is emitted as one JSON object per line via Output::json (mirroring the JSONL run-log shape). Stats are aggregated in both modes so print_summary can render totals.
