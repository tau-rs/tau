tau plugin run <binary> [--interactive | --script <path>] — standalone plugin REPL / scripted driver.

Per spec §9 (debug tier): spawns an arbitrary plugin binary (typically built locally without going through tau install), drives the handshake, and lets the operator pump requests through either an interactive REPL or a scripted JSONL file. The handler never installs the plugin into a lockfile; the binary path is the only contract.

Wire protocol details mirror [tau_runtime_tokio::plugin_host] but the implementation is intentionally standalone: this command exists to probe arbitrary binaries that aren’t necessarily wired into a project, so we don’t reach for the LockedPlugin-keyed loader.
