tau embed — emit host-embedding glue for a target language (Phase 2 §5.2). --host js emits the project-independent @tau/embed-js scaffold; --host rust|c derive IR + WIT from --project (defaulting to the CWD) exactly like the EPIC 5.1 tau build --target rust-lib/wasm-guest paths, then render the native/C host scaffolds.
