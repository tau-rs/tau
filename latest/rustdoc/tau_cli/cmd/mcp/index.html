tau mcp <subcommand> — manage MCP server contracts.

See spec at docs/superpowers/specs/2026-06-01-beta-3-mcp-facilitator-design.md §10 (CLI surface) and ADR-0038.

Modules§

tau mcp diff <name> — read-only diff between pin file and live probe. Exit 0 if no drift, exit 64 if drift detected.

tau mcp pin <name> [--from URL] — probe a server and write its contract to .tau/mcp/<name>.contract.json.
refresh
tau mcp refresh <name> — re-probe and overwrite the pin; report diff.
show
tau mcp show <name> — show a pinned MCP contract.
