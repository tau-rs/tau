Tracing-subscriber configuration for tau-cli.

The CLI’s job is to map clap flags onto a final filter directive. Subscriber install itself lives in [tau_observe::install] so the CLI and plugin SDK share one code path (sub-project A consolidation).

Per spec §3.7: stderr-targeted subscriber, default level INFO scoped to tau=*, verbosity flags promote (-v: DEBUG, -vv: TRACE), –quiet demotes to WARN, –debug behaves as -v plus expanded error chain at print time, RUST_LOG overrides everything.
