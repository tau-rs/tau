Crate tau_ports 

Source
Expand description

Port (trait) definitions for tau’s hexagonal architecture. Host crates (tau-runtime-tokio, the sandbox adapters, tau-pkg, …) implement these traits.

tau-ports defines four trait families:

  • llm::LlmBackend — LLM provider plugins (kind = "llm-backend").
  • tool::Tool — tool plugins (kind = "tool").
  • storage::Storage — storage plugins (kind = "storage").
  • capability_gate::CapabilityGate — universal capability gate contract; concrete impls live in tau-sandbox-{native,container,darwin,windows}.

See docs/decisions/0003-tau-ports.md for the design rationale.
