Enum LlmProviderMessage

#[non_exhaustive]
pub enum LlmProviderMessage {
    User {
        content: Vec<ContentBlock>,
    },
    Assistant {
        content: Vec<ContentBlock>,
    },
    ToolResult {
        tool_use_id: String,
        content: Vec<ContentBlock>,
        is_error: bool,
    },
}
Expand description

One message in the LLM-call shape, distinct from the agent-runtime tau_domain::Message envelope. See module-level docs for the layer separation.

Variants (Non-exhaustive)§

This enum is marked as non-exhaustive
Non-exhaustive enums could have additional variants added in future. Therefore, when matching against variants of non-exhaustive enums, an extra wildcard arm must be added to account for any future variants.

User-authored message content.

Fields

§content: Vec<ContentBlock>

Multi-block content; v0.1 admits ContentBlock::Text and ContentBlock::ToolUse only.

§

Assistant

Assistant-authored message content.

Fields

§content: Vec<ContentBlock>

Multi-block content; v0.1 admits ContentBlock::Text and ContentBlock::ToolUse only.

§

ToolResult

Result of a previously-issued tool call, fed back to the model.

Fields

§tool_use_id: String

Identifier matching the ToolUse::id of the call this result answers.

§content: Vec<ContentBlock>

Multi-block content describing the tool result.

§is_error: bool

Whether the tool reported an error.

Construct a LlmProviderMessage::ToolResult addressed to the given tool_use_id. Pair with the id of the LlmProviderMessage::Assistant tool-use this is answering.
