Storage port — kind = "storage" plugin contracts.

Namespace and Key are validating newtypes used by the Storage trait. Per the G8 scope-handling intent, tau-runtime is responsible for composing scope information into a Namespace; storage plugins treat the namespace as opaque and never parse or interpret it.
