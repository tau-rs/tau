Per-concern error enums for tau-ports.

Each error type is #[non_exhaustive] so additive variants are non-breaking. All errors derive Debug + Error + Clone + PartialEq + Eq; tests with free-form String fields use matches!() to avoid brittle wording comparisons.

LlmError, ToolError, StorageError, and CapabilityError are the per-trait error types. NamespaceError and KeyError are the validation errors for the Namespace and Key newtypes.
