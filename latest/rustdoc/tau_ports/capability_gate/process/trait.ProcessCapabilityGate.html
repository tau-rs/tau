Expand description

Extension trait: adapters that gate process spawn boundaries.

Implementors must also implement the universal CapabilityGate.

Required Methods§

Source

async fn wrap_spawn( &self, plan: &CapabilityPlan, cmd: &mut Command, ) -> Result<CapabilityHandle, CapabilityError>

Apply gate enforcement to a Command in preparation for spawn. On Linux native, this registers pre_exec hooks. The returned CapabilityHandle holds any ambient resources (cgroup, namespace fd) and releases them on Drop.

Provided Methods§

Source

async fn apply_post_spawn( &self, plan: &CapabilityPlan, child_pid: i32, handle: &mut CapabilityHandle, ) -> Result<(), CapabilityError>

Adapter-specific post-spawn setup. Called after cmd.spawn() succeeds and the child PID is known. Default: no-op.
