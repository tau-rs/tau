DynProcessGate — object-safe (dyn-compatible) form of ProcessCapabilityGate.

ProcessCapabilityGate uses async fn in trait (AFIT), which is not dyn-compatible, so a host that must store a process gate behind a trait object — e.g. the MCP stdio transport in tau-mcp-tokio — stores Arc<dyn DynProcessGate>. The blanket impl below means every ProcessCapabilityGate (every sandbox adapter, super::passthrough::PassthroughGate) is automatically a DynProcessGate, so adapters need no extra code.

This lives in tau-ports (behind the process feature) rather than a host crate so a transport crate can depend on the port without pulling in a whole host runtime and its sandbox/plugin graph. See ADR-0062.
