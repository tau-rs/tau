Module capability_gate 

Source
Expand description

Capability gate port — the tau_ports::CapabilityGate trait + supporting types.

Hexagonal port: tau-runtime consumes this trait; tau-sandbox-native, tau-sandbox-container, and MockCapabilityGate (in crate::fixtures) implement it. The runtime selects an adapter via a probe-based chain configured in <scope>/.tau/config.toml.

Stable as of v0.1 of the sandboxing sub-project. Variant evolution is handled by #[non_exhaustive] on every public type.
