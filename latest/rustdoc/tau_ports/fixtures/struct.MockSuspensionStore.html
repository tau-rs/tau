In-memory SuspensionStore for tests. One suspension per run (last write wins), mirroring the host FileCheckpointStore semantics.

fn delete_suspension(&self, run_id: &RunId) -> Result<(), CheckpointError>

Remove the suspension for run_id, if any. Idempotent: absent = Ok(()). Called after a resumed run completes so a stale snapshot cannot be re-resumed (which would re-run the post-suspend steps). Default no-op for stores that do not need cleanup.
