Struct MockCapabilityGate

pub struct MockCapabilityGate { /* private fields */ }
Expand description

Mock CapabilityGate adapter for tests. Reports Available with Tier::None, supports every known [CapabilityShape] except [CapabilityShape::Custom], and enforces nothing (all plans pass validate_plan for known shapes).
