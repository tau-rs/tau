Test fixtures for tau-domain types.

Gated behind the test-fixtures feature (off by default). Downstream crates depend via:

[dev-dependencies]
tau-domain = { workspace = true, features = ["test-fixtures"] }

All helpers are deterministic where possible; UUID-based ones (any_message, any_agent_definition-derived IDs) generate fresh v7 UUIDs each call.
