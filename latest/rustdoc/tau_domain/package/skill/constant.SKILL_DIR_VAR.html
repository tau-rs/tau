Public string constant for the ${SKILL_DIR} interpolation variable that resolves at runtime to the absolute path of the installed skill’s directory.

Parallel to the conventional ${SCOPE} and ${PROJECT} variables (also symbolic in v1; substitution lives outside tau-domain).

Used in capability paths entries and SKILL.md body references. Validated for syntactic recognition at install time (Skills-2); substituted at spawn time (Skills-4).
