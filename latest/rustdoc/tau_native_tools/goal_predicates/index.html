no_std goal-predicate registry — ported verbatim from tau-cli/src/cmd/builtin_registry.rs’s five builtin_* bodies that do not require std (schema_valid needs the jsonschema crate, which is std, and stays in tau-cli).

Behind the goal-predicates feature so callers that don’t need control flow (e.g. today’s tau-native-tools consumers) don’t pay for regex-automata.

Args contract (args is the JSON object built by the caller): matches the CLI registry byte-for-byte —

{ "present": bool, "content": string | null, ...predicate_params }
