fn complete(&mut self, request_json: String) -> Result<String, String>

Delegated inference. request-json is a serialized tau_ports::llm::CompletionRequest; returns a serialized CompletionResponse. Cassette-backed in conformance.

Source

fn now_millis(&mut self) -> u64

Monotonic-ish wall clock in milliseconds (deterministic in conformance).

Source

fn next_u64(&mut self) -> u64

Next u64 from the host RandomSource (deterministic in conformance).

Source

fn emit_event(&mut self, event_json: String)

Stream one RunEvent to the host as it is produced. event-json is a serialized tau_runtime_core::stream::RunEvent (externally-tagged serde). Fire-and-forget: no return, the guest does not observe host errors.
