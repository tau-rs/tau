Auto-generated bindings for an instance a component which implements the world runner.

This structure can be created through a number of means depending on your requirements and what you have on hand:

  • The most convenient way is to use Runner::instantiate which only needs a Store, Component, and Linker.

  • Alternatively you can create a RunnerPre ahead of time with a Component to front-load string lookups of exports once instead of per-instantiation. This method then uses RunnerPre::instantiate to create a Runner.

  • If you’ve instantiated the instance yourself already then you can use Runner::new.

These methods are all equivalent to one another and move around the tradeoff of what work is performed when.
