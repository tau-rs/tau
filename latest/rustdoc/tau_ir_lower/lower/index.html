Module lower 

Source
Expand description

Lowering pass: tau_pkg::ProjectConfig → IrModule.

The lowering pass is pure: it consumes an already-parsed ProjectConfig, resolves external references against caches the caller supplies (native tool registry, MCP contract cache, skill content-hash table), runs the capability-fit check against the target triple, and produces a typed IrModule. Any error short- circuits with LowerError.

tau build is the caller; tau dev is also a caller (it lowers once per source change to drive the interpreter against a fresh IR).
