IR-level error type.

Variants§

§

UnknownToolRef

Workflow-shape error: an Agent references a Tool that doesn’t exist in the workflow.

Fields

§agent: AgentId

Agent that contains the bad reference.

§tool: ToolId

The unknown tool id.

§

UnknownSubflowTarget

Workflow-shape error: a SubflowEdge::Spawn targets an Agent that doesn’t exist.

Fields

§subflow: SubflowId

The subflow.

§agent: AgentId

The unknown target.

§

SubflowCapNotSubset

Workflow-shape error: a SubflowEdge::Spawn’s cap_subset is not a subset of the parent agent’s grant.

Fields

§subflow: SubflowId

The offending subflow.

§

CapabilityFitFailed

Capability-fit failure (D-3b). One or more required capability shapes are not supported by the build target.

Fields

§missing: Vec<CapabilityShape>

The shapes that the target does not support.

§tools: Vec<ToolId>

Diagnostic: which tools required them.

§

FeatureUnsupported

Feature-fit failure (EPIC 4.2). The workflow uses one or more IR execution features the build target cannot run — e.g. any control-flow (Branch/Parallel/Loop) for a wasm target, whose guest drives run_ir_streaming and has no run_pipeline control-flow path.

Fields

§missing: Vec<IrFeature>

The features the target does not support.

§target: TargetTriple

The target that lacks them.

§

UnknownDeterministicFn

A Deterministic step references a function name that the lowering registry doesn’t know.

Fields

§step: StepId

The step id.

§fn_name: String

The unresolved name.

§

UnknownNativeTool

A ToolImpl::Native reference’s content hash could not be resolved (the native tool registry did not know the symbolic name).

Fields

§tool: ToolId

The tool id that contains the unresolved native ref.

§fn_name: String

The native fn name that was not resolved.

§

UnknownSubflowToolTarget

A ToolImpl::Subflow tool targets an agent that is not present in the workflow.

Fields

§tool: ToolId

The tool id whose Subflow variant points at a missing agent.

§agent: AgentId

The unresolved target agent id.

§

UnknownStepToolTarget

A ToolImpl::Step tool references a step id that is not present in the workflow’s steps table.

Fields

§tool: ToolId

The tool id whose Step variant points at a missing step.

§step: StepId

The unresolved step id.

§

PromptFileUnreadable

An agent’s system_file prompt could not be read at build time. This deliberately moves prompt-file existence from run time to build time (D6-B): a missing or unreadable prompt file is a hard build error.

Fields

§agent: AgentId

The agent whose system_file prompt failed to load.

§path: String

The prompt file path, as written in the config.

§reason: String

Why the read failed (from the injected prompt_file reader).

§

Parse(String)

Generic parse failure surfacing from the upstream TOML parser.

§

McpBuild(McpBuildError)

MCP-specific build error (per β.3 design doc §5).

§

UnsupportedComposeSubflow

SubflowEdge::Compose is not yet implemented (v0 reserves the variant).

Fields

§subflow: SubflowId

The offending subflow.

§

UnknownTriggerAgent

A trigger binding names an entrypoint agent that is not present in the workflow.

Fields

§trigger: String

The trigger name.

§agent: AgentId

The unresolved entrypoint agent id.

§

UnknownPipelineRun

A pipeline step’s run target does not exist in the workflow.

Fields

§step: String

The pipeline step id.

§target: String

The unresolved kind:id target, e.g. agent:writer.

§

DuplicatePipelineStepId

Two pipeline steps share an id.

Fields

§id: String

The duplicated id.

§

ForwardOutputRef

${steps.x.output} references a step that runs at or after this one.

Fields

§step: String

The referencing step.

§referenced: String

The referenced (later/self) step id.

§

UnknownOutputRef

${steps.x.output} references a step id not in the pipeline.

Fields

§step: String

The referencing step.

§referenced: String

The unknown referenced id.

§

BadPipelineTemplate

A pipeline input template was malformed (unterminated/unrecognized).

Fields

§step: String

The step id.

§detail: String

Human-readable template error.

§

UnknownCheckRef

A StepRun::Check references a check id absent from workflow.checks.

Fields

§step: String

The pipeline step id that contains the bad reference.

§check: String

The check id that was not found in workflow.checks.

§

UnknownContextTransformer

A context pipeline names a transformer that is neither a known builtin nor a declared custom node.

Fields

§agent: String

The agent id whose context pipeline is invalid.

§transformer: String

The offending transformer name.

§

ContextFitBudgetNotLast

A context pipeline’s last step is not the builtin fit_budget.

Fields

§agent: String

The agent id whose context pipeline is invalid.

§last: String

The actual last transformer name.

§

DuplicateContextTransformer

A context pipeline repeats a transformer name.

Fields

§agent: String

The agent id whose context pipeline is invalid.

§transformer: String

The repeated transformer name.

§

UnknownCheckLocus

A check’s Locus::Output references an unknown or later pipeline step.

Fields

§check: String

The check id whose locus is invalid.

§output: String

The referenced step id that is missing or comes at/after the check step.

§

LoopMaxItersZero

A StepRun::Loop has max_iters == 0, which would never execute a body iteration. The bound must be at least 1.

Fields

§step: String

The pipeline step id containing the offending Loop.

§

UnknownDeterminism

A context step declares a determinism class string that lowering does not recognize (D7-B / ADR-0065). Replaces the former silent _ => DeterminismClass::Pure default, which downgraded an unknown string to the most permissive class.

Fields

§agent: String

The agent id whose context pipeline is invalid.

§transformer: String

The offending transformer name.

§determinism: String

The unrecognized determinism string as authored.

§

UnsupportedPromptKind

Lowering encountered a PromptEntry variant it does not know how to lower (D7-B / ADR-0065). Replaces the former silent wildcard that mapped an unknown prompt kind to an empty prompt. Only reachable if a future #[non_exhaustive] PromptEntry variant is added upstream without a corresponding lowering arm — a fail-closed guard, not a user-authoring error.

Fields

§agent: AgentId

The agent whose prompt could not be lowered.

§detail: String

Debug rendering of the offending PromptEntry.

§

ConditionUnknownOutput

A Condition::evaluates is a Locus::Output(id) that names a step not yet visible at this point in the pipeline.

Fields

§step: String

The pipeline step id containing the condition.

§output: String

The referenced step id that is missing or out of scope.
