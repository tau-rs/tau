TypeScript source extractor — produces ProjectConfig from a project.ts source via swc-based static AST analysis.

See docs/superpowers/specs/2026-06-10-beta-8-ts-authoring-design.md and ADR-0041 (forthcoming) for the design.

β.8 v1 scope: declarations only. Tool bodies (run: async () => ...) are rejected at parse time. δ.2 will add runtime JS execution via QuickJS embed for inline tool bodies.
