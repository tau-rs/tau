Container sandbox adapter for tau.

Shells out to docker or podman to wrap plugin processes in a container with capability-derived isolation. Works on any host with one of the runtimes installed (Linux / macOS / Windows with Docker Desktop).

Compared to tau_sandbox_native:

  • Pros: cross-platform; stronger isolation (full container); no kernel feature requirements (works on macOS/Windows hosts).
  • Cons: requires docker/podman on PATH; container-start latency (~50-200 ms cold); image management (pull / authentication).
