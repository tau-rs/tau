Expand description

Run a plugin that implements [Storage]. Reads frames from stdin, writes frames to stdout. Returns when the host sends meta.shutdown or stdin closes.

v0.1 stub: handshake works; storage.* methods return METHOD_NOT_FOUND until the host wiring lands.

§Example

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    tau_plugin_sdk::run_storage(
        MyStorage,
        env!("CARGO_PKG_NAME"),
        env!("CARGO_PKG_VERSION"),
    ).await?;
    Ok(())
}
