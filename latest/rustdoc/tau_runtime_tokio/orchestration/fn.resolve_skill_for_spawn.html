Expand description

End-to-end resolution. Looks up the skill via the injected [SkillResolver] port, substitutes ${SKILL_DIR}, narrows by scope_paths, verifies the subset law, returns the request.

parent_grant is the parent agent’s effective capability grant — used for the v1.1 capability subset law.

Requires the host-fs feature: returns a SkillSpawnRequest whose install_path is a std::path::PathBuf. Guest shells without host-fs cannot construct the request and never call this; they ship tau_ports::NoSkillResolver so a skill.<name>.spawn fails gracefully.
