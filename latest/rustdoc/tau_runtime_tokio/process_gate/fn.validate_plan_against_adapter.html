pub fn validate_plan_against_adapter<S: CapabilityGate>(
    plan_id: &str,
    plan: &CapabilityPlan,
    adapter: &S,
) -> Result<(), Vec<SandboxValidationError>>
Expand description

Cross-check every capability in plan against adapter.supported_shapes().

All unsupported capabilities are collected before returning — the error Vec may contain more than one entry. This is the key value of Layer 3: a single tau check run surfaces every problem at once.

§Arguments

  • plan_id — free-form identifier carried into each SandboxValidationError so callers can format messages like "plugin foo: capability fs.read shape unsupported by adapter X". Typically a plugin id.
  • plan — the [CapabilityPlan] to validate.
  • adapter — any [CapabilityGate] implementor (e.g. SandboxAdapter from the chain, MockCapabilityGate from fixtures, or another test double).

§Returns

Ok(()) if every capability shape in plan is in adapter.supported_shapes(). Err(errors) with the complete list of failures otherwise.

§Example

use tau_domain::Capability;
use tau_ports::{CapabilityPlan, fixtures::MockCapabilityGate};
use tau_runtime_tokio::process_gate::validate_plan_against_adapter;

let adapter = MockCapabilityGate::new("mock");

// A standard fs.read capability is supported by MockCapabilityGate.
let cap: Capability = serde_json::from_value(
    serde_json::json!({"kind": "fs.read", "paths": ["/tmp/**"]})
).unwrap();
let plan = CapabilityPlan::new(vec![cap], None, None);
assert!(validate_plan_against_adapter("my-plugin", &plan, &adapter).is_ok());

// An empty plan always passes.
let empty = CapabilityPlan::new(vec![], None, None);
assert!(validate_plan_against_adapter("my-plugin", &empty, &adapter).is_ok());
