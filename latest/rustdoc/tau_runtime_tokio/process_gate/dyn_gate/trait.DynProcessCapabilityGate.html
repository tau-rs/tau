Expand description

Object-safe wrapper of [ProcessCapabilityGate] with boxed-future methods.

Implemented automatically for every ProcessCapabilityGate via the blanket impl below. Callers store Arc<dyn DynProcessGate> and invoke DynProcessGate::wrap_spawn to gate a subprocess spawn.
