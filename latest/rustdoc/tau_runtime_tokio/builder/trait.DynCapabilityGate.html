Expand description

Object-safe wrapper of [CapabilityGate] (the universal four methods). Stored in registries that don’t care about process extensions (wasm host, MCU, MCP facilitator).

The process-spawn extension (DynProcessCapabilityGate) lives in tau_runtime_tokio::process_gate and depends on std::process::Command.
