tau_sdk_codegen

Module schema 

Source
Expand description

Parse the frozen IR JSON schema into a lookup model.

Only the pieces the SDK emitters need are lifted out: the set of $defs (so emitters can assert a mirrored leaf type is real) and per-$def enum variants (so vocabulary enums are sourced from the schema, not hardcoded).
