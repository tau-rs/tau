Contract types — what tau build pins for an MCP server.

A ServerContract captures the server’s tools/list response + per-tool capability declaration. The canonical-hash module produces a Hash256 over the canonical-JSON bytes (β.2 canonical-encoder rules re-applied here). Pinned-contract file I/O lives in pinned. The resolver module provides the McpContractResolver port trait and the sync PinnedResolver impl (gated on with-std-adapters).
