Expand description

McpContractResolver port trait + impls.

The resolver feeds tau-ir’s Caches::mcp_contract closure. Two impls ship in v0:

  • PinnedResolver — sync; reads .tau/mcp/<entry>.contract.json per tau build --offline.
  • tau_mcp_tokio::resolver::LiveMcpContractResolver — async; performs the MCP handshake via host_lifecycle::open + tools/list.

Both impls populate a sync cache (BTreeMap<url, ResolvedMcpContract>) that the lowering stage reads through.
