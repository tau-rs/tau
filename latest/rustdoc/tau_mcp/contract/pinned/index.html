tau_mcp::contract

Source
Expand description

Pinned contract file shape.

Stored at .tau/mcp/<name>.contract.json by tau mcp pin <name>. Read by tau build --offline (PR-4) and by tau verify --bundle (PR-6). Carries the full ServerContract plus the URL and the pre-computed contract_hash so callers can read-and-trust without re-hashing (re-hash is still the runtime defense-in-depth check).
