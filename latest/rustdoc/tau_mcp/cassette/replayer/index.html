Cassette replayer.

Reads a cassette (JSONL bytes), matches inbound (host→server) requests against recorded Direction::In entries by (method, normalized args), and emits the matching recorded Direction::Out responses + notifications.

PR-3 wires this into a Transport impl that the in-memory test harness uses (cassette-as-transport).
