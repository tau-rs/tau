2//!
3//! A [`ServerContract`] captures the server's `tools/list` response +
4//! per-tool capability declaration. The canonical-hash module produces a
5//! `Hash256` over the canonical-JSON bytes (β.2 canonical-encoder rules
6//! re-applied here). Pinned-contract file I/O lives in [`pinned`].

8//! and the sync [`PinnedResolver`] impl (gated on `with-std-adapters`).
