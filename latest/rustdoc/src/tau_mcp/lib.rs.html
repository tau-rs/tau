1//! tau-mcp — MCP (Model Context Protocol) facilitator types.
2//!
3//! Pure types + canonical-hash + cassette format. No I/O, no tokio.
4//! Transports + lifecycle live in `tau-mcp-tokio`.
5//!
6//! # Modules
7//!
8//! - [`protocol`] — MCP wire types: JSON-RPC envelopes, the five v0 method
9//!   payloads (`initialize`, `tools/list`, `tools/call`,
10//!   `sampling/createMessage`, `roots/list`), notifications, cancellation.
11//! - [`contract`] — `ServerContract` (the schema + capability declaration
12//!   tau-build pins) + canonical hash (`Hash256` = SHA-256 of canonical
13//!   JSON) + pinned-contract file (de)serializer.
14//! - [`host`] — `HostHandlers` trait with default-deny baseline impl.
15//! - [`cassette`] — transport-agnostic message-level recorder + replayer.
16//! - [`transport`] — `Transport` trait shared by `tau-mcp-tokio` impls.
17//!
18//! # Spec
19//!
20//! [β.3 MCP facilitator design](https://github.com/LEBOCQTitouan/tau/blob/main/docs/superpowers/specs/2026-06-01-beta-3-mcp-facilitator-design.md).
