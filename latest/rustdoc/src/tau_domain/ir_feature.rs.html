1//! `IrFeature` — the vocabulary of optional IR execution features a target may
2//! or may not support.
3//!
4//! Analogous to [`CapabilityShape`](crate::CapabilityShape): where a shape says
5//! "this workflow needs filesystem-write, does the target enforce it?", an
6//! `IrFeature` says "this workflow uses a `Loop`, can the target execute it?".
7//! Leaf pipeline steps (agent/tool/deterministic/check) are the base surface and
8//! are **not** features — only the EPIC 4.1 control-flow constructs are.
9//!
10//! Placement rationale: both `tau-ports` (targets declare `supported_features`)
11//! and `tau-ir` (maps `StepRun` → `IrFeature`) reference this type, and neither
12//! may depend on the other. Like `CapabilityShape`, it lives in the innermost
13//! `tau-domain` vocabulary crate so dependencies point inward.
14
15/// An optional IR execution feature. A target's
16/// [`supported_features`](../../tau_ports/target/profile/struct.TargetCapabilityProfile.html)
17/// lists the ones it can execute; a workflow that uses a feature the target does
18/// not support is refused at build time (see `tau-ir-lower`'s `feature_fit`).
19///
20/// `Copy` (no heap-allocating variant), so sets are plain `&'static [IrFeature]`
21/// — no owned-set type is needed (contrast `CapabilityShapeSet`, whose
22/// `Custom { name }` variant forces an owned collection).
23#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, PartialOrd, Ord)]
24#[cfg_attr(feature = "serde", derive(serde::Serialize, serde::Deserialize))]
25pub enum IrFeature {
26    /// Conditional `Branch { on, then, otherwise }` (EPIC 4.1 / 4.2a).
27    Branch,
28    /// Concurrent fan-out/join `Parallel { branches }` (EPIC 4.1 / 4.2b).
29    Parallel,
30    /// Bounded `Loop { body, until, max_iters }` (EPIC 4.1 / 4.2c).
31    Loop,
32    /// Human-in-the-loop `Suspend { resume_signal }` (EPIC 4.1 / 4.3).
33    Suspend,
34}
35
36impl IrFeature {
37    /// Every control-flow feature, for targets that support all of them
38    /// (every native/host target today). Kept here so a new variant forces a
39    /// compile-visible update of this list alongside the enum.
40    pub const ALL: &'static [IrFeature] = &[
41        IrFeature::Branch,
42        IrFeature::Parallel,
43        IrFeature::Loop,
44        IrFeature::Suspend,
45    ];
46}
