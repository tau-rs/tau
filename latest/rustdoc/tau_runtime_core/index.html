Crate tau_runtime_core 

Source
Expand description

Executor-agnostic kernel of tau. Drives the agent loop independently of any async runtime. Host shells (tau-runtime-tokio, tau-runtime-embassy, future smol/async-std/glommio/wasm shells) link this crate and supply executor-specific adapters.

See docs/superpowers/specs/2026-05-30-tau-runtime-core-design.md for the design.
