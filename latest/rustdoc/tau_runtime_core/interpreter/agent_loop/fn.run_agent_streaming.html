Expand description

Execute one Agent node through the kernel agent loop, returning the uncollapsed crate::stream::RunEvent stream instead of a collapsed RunOutcome.

Construction is shared with run_agent via [prepare_agent_run] so the batch and streaming paths cannot drift. The conformance dev profile drives this to observe the per-event run (TextDelta / ToolCall* / TurnCompleted / RunCompleted) rather than the collapsed terminal outcome.

The returned stream is 'static: Runtime::run_streaming_with_history snapshots its tool registry and backend into Arc-clones that the stream owns, so the Runtime built here may be dropped after this call returns.
