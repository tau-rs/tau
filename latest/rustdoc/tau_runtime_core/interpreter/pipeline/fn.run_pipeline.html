Non-suspend convenience wrapper over run_pipeline_suspendable for callers that cannot pause (e.g. the bundle-run path in v1). Wires a no-op SuspensionStore and runs fresh (never resumes); a pipeline that hits a Suspend step errors RuntimeError::SuspendUnsupported instead of pausing. Callers that support HITL suspend/resume use run_pipeline_suspendable directly.
