Expand description

Sink for trace events emitted by the orchestration kernel.

Implementors: NoopTraceSubscriber (this module), MpscTraceSubscriber (tau-runtime tokio shell). Embassy / wasm shells provide their own.

The method is &self (shared reference) so subscribers can be held in Arc<dyn TraceSubscriber> — the subscriber is responsible for internal synchronisation if needed (e.g. Mutex<Sender>).
