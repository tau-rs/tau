Source
Expand description

Curated Variant B embedding surface (EPIC 7.1).

A product embeds tau by (1) decoding baked IR bytes with from_canonical_bytes, (2) resolving the entry agent via IrModule::entry_agent (sole-agent contract) or an explicit AgentId, (3) implementing ToolDispatcher — tool execution, DynLlmBackend resolution, and the mandatory Clock + RandomSource ports — and (4) driving run_ir (single outcome) or run_ir_streaming (RunEvent stream; the terminal RunEvent::RunCompleted fires exactly once).

Everything here is a re-export: this module pins which items form the supported embedding API. See docs/how-to/embed-rust-native.md for the worked example (crates/tau-embed-example).
