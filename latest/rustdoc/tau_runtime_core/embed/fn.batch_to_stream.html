Function batch_to_stream 

pub fn batch_to_stream(
    resp: CompletionResponse,
) -> Pin<Box<dyn Stream<Item = Result<CompletionChunk, LlmError>> + Send>>
Expand description

Convert a batch CompletionResponse into a CompletionStream that yields the equivalent chunks: zero-or-one [CompletionChunk::Text] (only when resp.text is non-empty), one [CompletionChunk::ToolUse] per entry in resp.tool_uses (in order), and one terminal [CompletionChunk::Finish] carrying resp.stop_reason and resp.usage.

Plugin authors with batch-only SDKs use this in their LlmBackend::stream impl: Ok(batch_to_stream(self.complete(req).await?)).

§Example

// Illustrative; `CompletionResponse` is `#[non_exhaustive]` so external
// callers must build it via the data-types builder added in T5.
let resp = /* CompletionResponse */;
let stream = tau_ports::batch_to_stream(resp);
