Agent-loop methods on Runtime and pure helper functions.

This module contains the methods that can run in any async executor (no tokio specifics), plus the pure free-function helpers used by the streaming pump (stream.rs in the host shell).

§What lives here vs. the host shell

  • Runtime::invoke_tool — single-tool direct dispatch; no LLM loop.

  • build_policy_denied_outcome, agent_messages_to_provider_messages, flatten_content_to_string, content_to_value — pure helpers used by the streaming pump.

  • narrowed_capability_for_session — stays in tau-runtime-tokio::run until capability_override migrates to core (it consumes a tau-pkg::EffectiveCapability, which tau-pkg owns).

  • run, run_with_history, run_default, spawn_root_agent — stay in the host shell until stream.rs and the orchestration submodules migrate to core (Tasks 3.6/3.7).

§Error routing

Methods return crate::error::RuntimeError (the core error). Host-shell callers whose return type is the shell-level RuntimeError get automatic ? conversion via #[from] CoreRuntimeError.
