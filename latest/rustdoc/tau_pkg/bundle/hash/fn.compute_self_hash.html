pub fn compute_self_hash(manifest: &BundleManifest) -> String
Expand description

Compute the canonical SHA-256 of a manifest with the bundle.sha256 and bundle.created_at fields zeroed. Does NOT mutate the input.

created_at is excluded from the hash domain so two builds of identical source produce identical hashes (per spec §2 stable-bundles decision). The field is preserved in the final on-disk manifest — only the hash domain excludes it.
