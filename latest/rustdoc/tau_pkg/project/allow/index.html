Root tau.toml [allow] constitution — deserialization, validation, and the validated AllowConfig. See ADR-0057 and docs/superpowers/specs/2026-06-22-epic-1-story-1.2-allow-config-design.md.

Story 1.2 scope: parse + internal well-formedness + round-trip ONLY. Subset enforcement, closed-world reference checks, and the absent-[allow] warning are stories 1.3–1.6.
