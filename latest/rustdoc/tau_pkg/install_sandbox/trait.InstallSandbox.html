Expand description

Port: lock down a std::process::Command before it is spawned.

Implemented by tau-cli’s RuntimeInstallSandbox. tau-pkg calls InstallSandbox::is_enforced for the fail-closed decision, then InstallSandbox::wrap immediately before spawning.

Required Methods§

Source

fn is_enforced(&self) -> bool

true iff this gate applies real OS enforcement (tier > None). A passthrough / no-op gate returns false, which tau-pkg treats as “cannot sandbox” for the fail-closed decision.

Source

fn wrap( &self, plan: &CapabilityPlan, cmd: &mut Command, ) -> Result<InstallSandboxGuard, InstallSandboxError>

Apply enforcement to cmd in preparation for spawn. The returned guard must outlive the spawned child.
