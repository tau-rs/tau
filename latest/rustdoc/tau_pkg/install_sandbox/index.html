Module install_sandbox

Expand description

Install-time sandbox port (audit S2).

tau-pkg cannot depend on tau-runtime-tokio (that crate already depends on tau-pkg — a cargo cycle), so it cannot reach the concrete SandboxAdapter. Instead it defines this narrow sync, dyn-safe port; tau-cli implements it with the real adapter and injects it via crate::InstallOptions.

The port is sync because tau-pkg’s build path is synchronous and because the runtime’s ProcessCapabilityGate::wrap_spawn is async fn in trait (not dyn-safe). The async bridge lives entirely in the tau-cli adapter.
