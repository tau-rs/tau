Cross-check a skill package’s installed directory against its tau.toml manifest. Called from install_with_options when manifest.kind() == PackageKind::Custom { kind: "skill" }.

4-step flow:

  1. Read SKILL.md from install_dir/<content_path>.
  2. Parse via tau_domain::parse_skill_md.
  3. Validate frontmatter.name == manifest.name().
  4. Reference lint (hard-fail): every ${SKILL_DIR}/<rel-path> in the body must have a covering fs.read glob.
