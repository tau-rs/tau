Module source_list 

Source
Expand description

Enumerate available versions at a [PackageSource].

Used by the resolver (crate::resolve) to pick a concrete Version for a (name, source, version_req) triple. For Git { rev: None } we shell out to git ls-remote --tags and filter the tag list to those parsing as semver::Version (after stripping a leading v if present). For Git { rev: Some(_) } the source is a single point in version space — we shallow-clone the rev into a tempdir, read the manifest, and return that one version.

See docs/superpowers/specs/2026-04-30-transitive-deps-design.md §5.4.
