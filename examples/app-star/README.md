## The shape

```text
app-star/
├── package.json            # theirs; + tau dep, postinstall runs `tau gen`
├── src/                    # their app — tau never touches it
│   ├── server.ts
│   └── routes/tickets.ts   # + 2 lines: import { pipelines }; .run()
├── tau/                    # everything tau AUTHORS, one folder
│   ├── tau.toml            # constitution: [allow], triggers; no entry needed
│   ├── agents/triage.md
│   ├── models/default.toml
│   ├── pipelines/triage.ts # scanned by convention; id = file path
│   └── gen/                # GENERATED typed client — gitignored in real repos
├── .tau/                   # everything tau MANAGES: pins (committed), runs
│   └── envs/local.state.toml
└── crates/app-star-tools/  # optional muscle: #[tau::tool] project Rust
```

`tau/` = what you author; `.tau/` = what tau manages. Definitions go
*into* the toolchain, `tau/gen` comes *out*, and app code only ever
touches what comes out.
