# Python Containerized App (uv)

Dummy FastAPI application demonstrating Python containerization with
[uv](https://docs.astral.sh/uv/) as the package manager.

## What this shows

- **`pyproject.toml`** — standard Python project metadata; uv reads it
  natively (no `requirements.txt`).
- **`uv.lock`** — deterministic lock file generated by `uv lock`.
- **Multi-stage `Dockerfile`** — dependencies are installed in a cached
  layer; only the app source triggers a rebuild on code changes.
- **`compose.yml`** — one-command local run with health checks.

## Quick start

### Local (without Docker)

```bash
# Install uv if you don't have it
curl -LsSf https://astral.sh/uv/install.sh | sh

# Create the lock file, install deps, and run
uv lock
uv run serve
# → http://localhost:8000
# → http://localhost:8000/docs  (Swagger UI)
```

### Docker

```bash
# Generate the lock file first (required by --frozen in the Dockerfile)
uv lock

# Build and run
docker compose up --build
# → http://localhost:8000
```
